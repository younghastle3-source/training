## ガイドの目的

ダイエットで得た体型を維持するため、減量終了後のカロリー、PFC、活動量、体重変化を段階的に調整する。

減量後に食事量を急増させたり、歩数や有酸素運動を一気に減らしたりせず、推定メンテナンスカロリーへ移行する。

## 重要な考え方

- ダイエット終了は、体重管理の終了ではない。
- 減量後1か月が、リバウンドを防ぐ上で特に重要。
- 体脂肪と、水分・グリコーゲンによる体重増加を区別する。
- カロリーと活動量は、一気に変えず段階的に調整する。
- 体重は日々の数値ではなく、週平均と複数週の傾向で判断する。

## リバウンド阻止の5ステップ

### ステップ1：カロリー収支を把握する

減量終了前に、以下を正確に確認する。

- 現在の1日当たり摂取カロリー。
- 有酸素運動の種類・時間。
- 1日の平均歩数。
- 筋トレ頻度。
- 複数週の平均体重減少ペース。

### ステップ2：食事量と活動量を段階的に調整する

- 食事を一気に増やさない。
- 有酸素運動を一気にゼロにしない。
- 歩数を一気に減らさない。
- 食事量の増加と活動量の削減を組み合わせ、推定メンテナンスへ近づける。

### ステップ3：炭水化物を中心に増やす

- タンパク質量は基本的に維持する。
- 脂質を必要量まで増やす。
- 残りの増加分を主に炭水化物へ配分する。

### ステップ4：1〜2週間観察する

- 予想メンテナンスカロリーで体重と体型を観察する。
- 水分による正常な増加か、脂肪増加を含む可能性があるか判断する。
- 必要なら摂取カロリーを微調整する。

### ステップ5：メンテナンスカロリーの変化へ対応する

- 体重が再び減少し始めた場合、メンテナンスカロリーが上昇した可能性がある。
- 摂取量を5〜10%ずつ増やし、新しい維持カロリーを探す。

## ステップ1：減量終了前のカロリー収支

### 必要なデータ

1. 1日当たりの摂取カロリー。
2. 有酸素運動と歩数を含む活動量。
3. 週平均体重の減少ペース。

### 原資料の体脂肪換算

原資料では、体脂肪1kgの減少に約7,200〜7,700kcalの累積赤字が必要としている。

この数値と週平均の減少量から、1日当たりの推定カロリー赤字を逆算する。

| 週平均の体重減少 | 原資料の1日当たり推定赤字 |
| ---: | ---: |
| 週0.2〜0.4kg減 | 約200〜450kcal |
| 週0.4〜0.6kg減 | 約450〜650kcal |
| 週0.6〜0.8kg減 | 約650〜850kcal |

### メンテナンスカロリーの推定式

```text
推定メンテナンスカロリー
= 現在の摂取カロリー
+ 体重減少から推定した1日当たりのカロリー赤字
```

この計算は推定。体重変化には水分、グリコーゲン、便通、塩分、炎症、月経周期なども影響するため、複数週の平均を使う。

---

## Aさんの計算例

### プロフィール

- 身長: 170cm
- 体重: 65kg
- 体脂肪率: 12%
- ゾーン2有酸素: 毎日30分
- 歩数: 1日10,000歩
- 筋トレ: 週4回
- 減量中の摂取量: 2,300kcal
- 週平均の体重減少: 0.4kg

### 計算

原資料では週0.4kg減少を、1週間で約3,500kcal、1日当たり約500kcalの赤字として計算している。

```text
2,300kcal ＋ 500kcal
= 推定メンテナンス2,800kcal
```

活動量が同じなら、2,800kcal程度まで増やしても体脂肪が増えない可能性が高いという推定。

炭水化物を増やすとグリコーゲンと水分が増え、体重が約1kg増える場合がある。これは即座に体脂肪が1kg増えたことを意味しない。

## ステップ2：絶対に避ける3つの急変

### 食事量を一気に増やす

推定メンテナンスを大幅に超える急激な摂取増加は、体脂肪増加につながる可能性がある。

### 有酸素を一気にゼロにする

有酸素による消費分が突然なくなると、食事量を増やしていなくてもカロリー収支が変化する。

### 歩数を一気に減らす

歩数はNEATの一部。減量中に高い歩数を維持していた場合、急減すると消費カロリーも下がる。

減量中の厳しいカロリー制限、高い歩数、有酸素を永久に続ける必要はない。ただし段階的に戻す。

---

## 食事と活動量の2つの調整パターン

Aさんの例: 週0.4kg減、推定赤字500kcal。

### パターン1：食事量のみ変更

有酸素30分と1万歩を継続できる場合。

| 項目 | 調整 |
| --- | --- |
| 有酸素 | 30分を継続 |
| 歩数 | 10,000歩を継続 |
| 摂取カロリー | 2,300→2,800kcal |
| 増加量 | ＋500kcal |

活動量を変えないため、推定赤字分を食事で補う。

### パターン2：食事と活動量を両方変更

毎日30分、週210分の有酸素を続けにくい場合。

| 項目 | 調整 |
| --- | --- |
| 有酸素 | 30分→15分、週210分→105分 |
| 摂取カロリー | 2,300→2,650kcal |
| 食事増加量 | ＋350kcal |

原資料では、有酸素30分で約300kcalを消費すると仮定し、半分にしたことで消費が約150kcal減るため、食事増加をパターン1より150kcal少なくしている。

> 注意: 有酸素30分の消費量は、体重、運動種目、強度、機器により大きく異なる。実測または体重推移で補正する。

### 共通原則

- 食事を増やす場合も、活動量を減らす場合も、一気に変更しない。
- 自分の生活スタイルに合う方法を選ぶ。
- 変更後は1〜2週間観察する。

## ステップ3：増やす栄養素

ダイエット中、タンパク質を維持し、脂質を必要最低量確保し、炭水化物でカロリーを調整していた場合、減量後は主に炭水化物を増やす。

### AさんのPFC例

| 栄養素 | 減量中2,300kcal | 減量後2,800kcal | 変更 |
| --- | ---: | ---: | ---: |
| タンパク質 | 150g／600kcal | 150g／600kcal | 変更なし |
| 脂質 | 50g／450kcal | 60g／540kcal | ＋10g／約90kcal |
| 炭水化物 | 310g／1,240kcal | 410g／1,640kcal | ＋100g／約400kcal |

※各マクロの丸めにより合計値には小さな差が生じる。

### タンパク質

- 減量中に確保していた必要量を維持する。
- 筋肉量の維持と回復を支える。

### 脂質

- 必要量まで少し増やす。
- 原資料では50gから60gへの増加例。
- ホルモン、細胞膜、脂溶性ビタミン吸収などを支える。

### 炭水化物

- カロリー増加の中心。
- 疲労回復。
- ストレス軽減。
- 筋グリコーゲン回復。
- トレーニングパフォーマンス向上。

---

## ステップ4：1〜2週間の経過観察

### 観察項目

- 朝の体重と7日平均。
- ウエスト。
- 同条件で撮影した写真。
- むくみ。
- 塩分と炭水化物の摂取量。
- 便通。
- トレーニングパフォーマンス。
- 睡眠、疲労、食欲。

### 体重が約1kg増えた場合

炭水化物1gは、原資料では約3gの水分を保持するとしている。グリコーゲンと水分の回復による1kg前後の増加は、正常範囲の可能性がある。

体脂肪が同量増えたと即断しない。

### 体重が1.5kg以上増えた場合

以下がなければ、水分だけでなく体脂肪も少し増えた可能性を検討する。

- 強いストレス。
- 塩分の大幅増加。
- 強い筋肉痛や炎症。
- 月経周期。
- 便通の変化。
- 睡眠不足。

### 原資料の調整例

「減量終了時＋500kcal」から「＋300kcal」へ戻し、数日から1週間程度観察する。

＋300kcalで体重が安定すれば、その付近が実際のメンテナンスカロリー候補。

## ステップ5：メンテナンスカロリーは変化する

食事量を増やし、体重と体型を維持できても、メンテナンスカロリーは固定ではない。

### TEF：食事誘発性熱産生

食べた物の消化、吸収、代謝に使われるエネルギー。食事量が増えるとTEFも増える。

### NEAT

減量中の省エネ反応で低下していた日常活動が、摂取量の増加により回復する可能性がある。

### トレーニング強度・筋肉量

炭水化物増加によりトレーニングパフォーマンスが上がり、消費エネルギーや筋肉量が増える可能性がある。

---

## NEATとは

NEATは`Non-Exercise Activity Thermogenesis`の略。運動以外の日常活動による消費エネルギー。

### 移動と姿勢

- 歩く。
- 立つ。
- 階段を使う。
- 姿勢を維持する。

### 家事と日常作業

- 掃除。
- 買い物。
- 料理。
- 通勤や移動。

### 無意識の動き

- 身振り手振り。
- 貧乏ゆすり。
- 姿勢変更などの細かな動き。

短期間で劇的に変わるとは限らないが、メンテナンスカロリーの変化に関係する。

## リバースダイエットの調整例

### 時系列

| 時期 | 摂取カロリー | 体重変化 | 判断 |
| --- | ---: | --- | --- |
| 減量終了時 | 2,300kcal | 週0.4kg減少 | 赤字状態 |
| 終了後0〜7日 | 2,800kcal | 水分で約0.5kg増加 | 正常な回復候補 |
| 終了後7〜14日 | 2,800kcal | 変化なし | 維持カロリー候補 |
| 終了後14〜21日 | 2,800kcal | 0.2kg減少 | メンテナンス上昇の可能性 |
| 終了後21〜28日 | 3,000kcal | 再観察 | ＋200kcal調整 |

### 体重が減り始めた場合

- 現在の摂取カロリーの約10%、原資料では200〜300kcalを追加する。
- 1〜2週間観察する。
- 体重が安定すれば新しいメンテナンス候補。
- 増え続ける場合は少し戻す。
- まだ減る場合は、さらに5〜10%増やして確認する。

## 原資料に掲載された実績例

原資料では、コーチング経験に基づく成果として以下を挙げている。

| 項目 | 原資料記載 |
| --- | ---: |
| 達成期間 | 2〜3か月 |
| 減量時からの追加カロリー | 800〜1,500kcal |
| 1回の増加幅 | 現在の約10% |

これらは保証値ではなく、個人差が大きい。体重、活動量、体脂肪率、食事記録の精度、減量期間、代謝適応などで変化する。

### 掲載事例

- 減量終了前: 1,800kcal。
- リバース1週目: 2,300kcal。
- 減量終了1か月後: 3,200kcal。
- 体重: 79.3kg→80.2kg。
- 体重増加: 1kg未満。
- 減量時からの摂取増加: ＋1,400kcal。
- リバース1週目からの増加: ＋900kcal。

原資料で報告された変化:

- 体脂肪率増加はほぼなし。
- 疲労が大きく低下。
- トレーニングパフォーマンスが改善。
- 高い食事量で体型を維持。

この事例を一般的な保証や標準速度として扱わない。

## カロリー調整の判断フロー

### 体重が減少する

1. 現在の摂取量を約10%増やす。
2. 1〜2週間観察する。

### 体重が安定する

- 現在の摂取量をメンテナンスカロリー候補とする。
- 歩数、有酸素、食事量をしばらく維持する。

### 体重が増加する

- 初期の1kg前後は、水分・グリコーゲンの可能性を確認する。
- 1.5kg以上増え、週平均も上がり続けるなら調整する。
- 原資料では、＋500kcalから＋300kcalへ戻す例。

### 調整後も増える

- 100〜200kcal単位で戻す。
- 活動量と記録誤差も確認する。

### 調整後も減る

- さらに5〜10%追加し、再観察する。

```text
体重減少 → 摂取を5〜10%増加 → 観察
体重安定 → 現行を維持
体重増加 → 水分要因を確認 → 必要なら100〜200kcal戻す
```

メンテナンスカロリーを無限に増やすことはできない。2〜3か月程度をかけて、体重と体型が安定する範囲を探す。

## 減量後1か月の運用ルール

### 継続するもの

- 朝の体重測定。
- 週平均体重の確認。
- 摂取カロリーの記録。
- タンパク質摂取。
- 歩数の記録。
- 筋トレ。
- 定期的な写真・ウエスト確認。

### 段階的に緩めるもの

- 有酸素運動の時間。
- 高すぎる歩数目標。
- 厳しいカロリー制限。
- 食事選択の制限。

### 急にやめないもの

- 体重管理。
- 食事量の把握。
- 日常活動。
- 筋トレ。

## AI利用時の解釈ルール

- 体脂肪1kg＝7,200〜7,700kcal、週減少量からの赤字計算は推定として扱う。
- 体重、水分、グリコーゲン、便通、塩分、炎症、月経周期を区別して判断する。
- 1日または数日の体重増加だけで、脂肪増加と断定しない。
- 「リバースダイエットで代謝が大幅に上がる」「カロリーを無限に増やせる」と表現しない。
- 原資料の実績例を、全員が再現できる保証として使わない。
- 摂取カロリーを増やす速度は、減量期間、現在の摂取量、体脂肪率、活動量、体調、食欲に合わせる。
- 減量後も体重増加への恐怖が強く、食事を増やせない場合は、摂食障害や不安への専門的支援を検討する。
- 18歳未満、妊娠・授乳中、摂食障害歴、無月経、強い疲労、失神、心疾患、糖尿病などがある場合は専門家へ相談する。
- 減量後の過食に対し、翌日の絶食、嘔吐、下剤、過剰運動などの懲罰的行動を勧めない。
- 体型維持だけでなく、睡眠、性欲、月経、トレーニング、気分、生活の自由度も成功指標に含める。
