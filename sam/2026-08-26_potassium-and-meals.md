# 2026-08-26 カリウムの役割と実践食事例

出典: Skool（SGIR HQ PREMIUM）・Sam Phillips

---

## カリウムの役割（超重要ミネラル）

### 関与する主要機能
- トレーニングパフォーマンス（電気信号・カリウム-ナトリウムポンプ）
- インスリン感受性・血糖値コントロール
- 体内・筋肉内の水分バランス（浮腫み防止・パンプ感改善）
- テストステロン最適化

### 高炭水化物食とカリウムの関係
- 糖質摂取 → インスリン分泌 → 糖と同時にカリウムも細胞内へ運ばれる
- 高炭水化物食ほど体内カリウム需要が高まる

### カリウム豊富な食材
| 食材 | 特徴 |
|------|------|
| ほうれん草 | 高カリウム・鉄分も豊富 |
| キウイ | カリウム＋セロトニン＋抗酸化作用 |
| じゃがいも | 高カリウム・消化しやすい炭水化物源 |
| さつまいも | 高カリウム・食物繊維も豊富 |
| メロン | 高カリウム |
| トマト | カリウム＋リコピン |

### 目標比率
- ナトリウム : カリウム = 1〜2 : 1 に近づける

### カリウムが整うと起きること
- 体内の水分バランスが整いむくみにくくなる
- 細胞内の水分保持が安定しパンプが上がる
- 神経伝達が正常に働く
- 筋収縮がスムーズになりパフォーマンス向上
- 足つり予防
- 血圧コントロール
- インスリン感受性・糖代謝の改善
- グリコーゲン貯蔵の効率化
- 疲労感・だるさの軽減

## 15kmラン後のリカバリー食

| 食材 | 量 |
|------|---|
| 牛もも肉（挽肉） | 300g |
| 白米 | 300g |
| ほうれん草 | 200g |
| グリーンキウイ | 1個 |

- ほうれん草＋キウイで計1500mg近いカリウムを摂取
- ナトリウム（塩3〜4g≒1500mg）とカリウムの比率を1:1に近づけた構成

## 夜ご飯レシピ

| 食材 | 量 |
|------|---|
| 牛もも肉 | 250g |
| じゃがいも | 300g |
| たまねぎ・ズッキーニ・パプリカ | 適量 |

### エアフライヤーじゃがいものコツ
1. 小さく切って切り口を洗い、デンプンを落とす
2. 冷蔵庫に30分入れて水気を取る
3. スプレーオイル＋ケイジャンシーズニングをつける
4. 200°で20分（10分でひっくり返す）

## 外食（ポケボウル）の食事例

### マクロ栄養素
| 栄養素 | 量 |
|------|---|
| タンパク質 | 120g |
| 脂質 | 30g |
| 炭水化物 | 150g |
| 合計カロリー | 約1300〜1400kcal |

### 食材内訳

**タンパク質源:**
- サーモン（特にトラウトはオメガ3の王様）
- マグロ（鉄分・ビタミンD/B12・セレン・タウリン豊富）
- 枝豆（植物性だがアミノ酸スコアが高い）
- 鶏胸肉（B3・B6・セレン）

**脂質源:** 主にサーモン

**炭水化物源:**
- 白米（消化しやすい）
- コーン（食物繊維）
- マンゴー（食物繊維・ビタミンA/C・カリウム）

**食物繊維・その他:**
- もずく（フコイダン・水溶性食物繊維・ヨウ素・ほぼカロリーゼロ）
- トマト（リコピン・カリウム）
- オニオン
