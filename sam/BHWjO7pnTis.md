# [You Can Do It Too] 6 Essential Rules for Guaranteed Diet Success That I Learned the Hard Way

- チャンネル名: SAM Get It Right
- 動画URL: https://www.youtube.com/watch?v=BHWjO7pnTis

ダイエットを長期的に成功させ、目的の体を手に入れるために欠かせない絶対条件として、6つのルールが提示されている。動画では概要のみが語られており、詳細はスライドPDF（概要欄に掲載）に記載されているとのこと。

## ルール1：自分の摂取カロリーを把握する

- 口に入れるもの全てに注意を払うことが必要。
- 一生ずっとカロリー計算を続ける必要はない。マイフィットネスパルなどに毎回記録し続ける義務はない。
- ただし、今の状態から抜け出したい・変わりたいのであれば、今の状態になった原因（これまで食べてきたもの・飲んできたもの）を理解する必要がある。
- **ダイエットを始めて少なくとも最初の3ヶ月間**は、自分がどれだけのカロリーを摂取しているかを記録する必要がある。
- カロリーを記録していないと、どれくらいの摂取カロリーで体脂肪が落ちる「アンダーカロリー」になるのか、逆に太ってしまう「オーバーカロリー」になるのかが分からない。
- 「1500kcalしか食べていないのに痩せない」と言う人の**99.9%**は、単純に自分の摂取カロリーを正確に把握できていないだけ。
- カロリーは朝昼晩の食事だけでなく、以下も全て記録・カウントされる。
  - 完食でつまんだもの
  - スターバックスのコーヒーに入れた砂糖・ミルク
  - 卵を焼くときに使った調理油
- 「測定しているものは改善できる（measure it, improve it）」という格言の通り、カロリーを測定できていなければ改善のしようがない。
- 体重が停滞すると多くの人は「代謝のせい」にするが、体重が落ちれば体は小さくなり消費カロリーも自然に少なくなるため、元の摂取カロリーのままでは体重が落ちにくくなるのは当然のこと。
  - ダイエットによって、NEAT（非運動性熱産生）や食事誘発性熱産生（食事の消化に使うカロリー）が減少し、体重が停滞するという要因もある。
- ダイエットを進める中で、例えば2500kcalからスタートしてずっと2500kcalのままで体重が落ち続けるわけではない。メンテナンスカロリー（体重維持カロリー）は体重の低下や摂取カロリーの減少に伴って徐々に低くなっていくため、ダイエットの進行に応じてカロリーを調整していく必要がある。
- カロリー計算ができていなければ、どれだけカロリーを落とせばよいか、停滞を抜けるためにどう調整すればよいかも分からなくなる。
- 自分がどれだけのカロリーを摂取しているかを知ることは避けて通れない道である。

## ルール2：自分のメンテナンスカロリーを大体でいいから把握する

### 基本定義

- メンテナンスカロリー＝1日に消費するカロリーのこと。
- メンテナンスカロリーより**高く**摂取した分は、基本的には体脂肪として貯蔵される（まれに筋肉になることもある）。
- メンテナンスカロリーより**低く**摂取すれば、体重は必ず落ちる。
- これは熱力学の法則であり、「この食材を食べたら太る」「この食事法だから太る」といった主張はダイエット法以前の次元の話であり誤り。消費カロリーより摂取カロリーが少なければ、その不足分は体（基本的には体脂肪、タンパク質を摂らず筋トレもしていない場合は筋肉が使われることもある）からどこかで補われる。

### メンテナンスカロリーの把握方法（100%正確ではないが80%程度の精度の目安になる）

1. **TDEE計算機**をGoogleで検索し、身長・体重・活動量を入力して算出する。
2. **体重 × 30〜40kcal** で概算する。
   - 活動量が低い人（デスクワーク中心・筋トレのみ）：×30
   - 活動量が多い人（1日1万歩以上＋筋トレ＋有酸素運動）：×40
   - 例：週3〜4回筋トレ、1日1万歩、体重70kgのAさんの場合 → 70×35＝**2450kcal**（予想メンテナンスカロリー）。この場合2450kcalより低いカロリーを摂取すれば体脂肪は落ちていく。

### ダイエット開始カロリーの決め方と調整方法

- 上記いずれかの方法で出したメンテナンスカロリーから**約300kcal引いた値**からダイエットを開始する。
- 体重70kg・メンテナンスカロリー2450kcalのAさんの例で、2000kcalからダイエットを開始した場合：
  - **週0.5kgペースで理想的に落ちている**場合：それが自分にとって理想的なアンダーカロリーなので、カロリーは変えずそのまま継続する。
  - **週1kgなど早いペースで落ちすぎている、または食欲コントロールがきついほど空腹が強い**場合：計算式で出したメンテナンスカロリーより実際は高かった可能性があるため、**200kcal前後カロリーを追加**して様子を見る。
  - **-200kcalしても体重が落ちない**場合：計算式で出したメンテナンスカロリーより実際は低かった可能性があるため、**200kcal前後カロリーをさらに減らして**体重がしっかり落ちるか確認する。
- ちゃんとカロリー計算ができていて、メンテナンスカロリーより低い食事ができていれば、ほとんどの人は体重が必ず落ちる。

## ルール3：タンパク質を体重×2倍摂取する

- 筋タンパク合成を最適化する上では、体重×1.6〜1.8倍程度でも十分な可能性が高く、2倍摂取する厳密な理由はないかもしれない。
- それでも体重×2倍を推奨する理由：
  - タンパク質（特に動物性タンパク質）は最も栄養価が多く含まれる。
  - 空腹感を抑制してくれる。
  - 消化・利用の過程（食事誘発性熱産生）で最も多くの熱を消費する＝炭水化物や脂質と比べてカロリーを消費しやすく、**最も太りにくい栄養素**である。
- 何をすればよいか分からない人は、まずタンパク質の量を増やすことから始めるとよい。特に意識しなくても、肉・魚・卵・乳製品を食事に追加してタンパク質量を増やすだけで、食べすぎの予防になり、食事の栄養価の摂取が大きく上がる。
- ダイエット中の人はタンパク質2倍を目標に摂取するとよい。

## ルール4：週3回以上の筋トレと1日1万歩をライフスタイルとして受け入れる

- 「ダイエットだからやる」「筋肉をつけたいからやる」ではなく、**もうやって当たり前のライフスタイルの一部**として受け入れる必要がある。
- 痩せたい、いい見た目を保ちたい、健康な状態になりたい、自信を持てる自分でありたいと思うなら、週3回以上の筋トレと1日1万歩は最低限やるべきこと。
- これができない・やりたくないのであれば、目指している体や体重は手に入らないものだと思った方がよい。
- いい見た目やかっこいい体、健康的な体という大きな価値のあるものには必ず犠牲が伴う。何もせずにかっこいい体・健康な状態を保てるのは恵まれた遺伝子を持つごく一部の人のみで、99.9%の人（この動画を見ている人を含む）は筋トレや1日1万歩をしないとその状態は作れない。
- 毎日夜寝る前の歯磨きと同様、避けて通れないライフスタイルとして受け入れる必要がある。

## ルール5：十分な睡眠をとる

睡眠不足がダイエットに与える悪影響として、以下が挙げられている。

| 睡眠不足による影響 | 内容 |
|---|---|
| 回復 | トレーニングからの回復ができなくなる |
| ホルモン | テストステロンが低下する |
| 体組成 | 脂肪ではなく筋肉が落ちやすくなる |
| 食欲 | 食欲のコントロールが難しくなる |
| 空腹ホルモン | グレリンの分泌量が高くなる |
| 腸内環境 | 腸内環境が悪くなる |
| インスリン感受性 | 低下し、摂取した栄養が体脂肪になりやすくなる |

- 睡眠はリスペクトすべき。ダイエットを成功させたいのであれば**最低6時間**は寝るべきである。

## ルール6：完璧主義ではなく継続主義になる

- 1ヶ月ダイエットして腹筋が割れなかったからといって、そこで諦めて食生活を崩すのは間違い。1ヶ月の悪い食生活・生活習慣・筋トレや運動をしない状態で今の体になったわけではないのと同様、数週間で大きな結果が出るとは思わない方がよい。
- **ダイエットはスプリントではなくマラソン**。短期間で目標の体が手に入らなくても、伝えた内容を日々のライフスタイルとして受け入れ継続すれば、体はすぐには変わらなくても徐々に変わっていく。
- あと何kg落とさなければいけない、あと何ヶ月ダイエットしなければいけない、といったゴールまでの道のりばかり考えるのではなく、**今日1日をその日の勝負**だと思って、その日決めたトレーニングや食事をこなすことを意識する。これが積み重なれば結果は必ずついてくる。
- 100%完璧な食事・完璧な有酸素運動を**30日間**しかできない人よりも、たまには食べすぎる・外食する・旅行に行くといった日があっても**70〜80%の努力を90日間継続できる人**の方が、確実に結果が出る。
- 失敗しても大丈夫。1日食べすぎてしまっても、次の日から切り替えれば問題ない。1回の失敗でこれまでの努力を消さないようにする。
  - 例：2500kcalでダイエットしているつもりが5000kcal食べてしまった場合、罪悪感を持って翌日に何時間も有酸素運動をしたり断食したりする必要はない。オーバーした分は「ハードにトレーニングできるぞ」くらいの受け止め方で十分。
- 90日間、ダイエット成功まで毎日完璧にできる人はほぼいない（動画内では「クリスティアーノ・ロナウドくらい」という表現で例えられている）。話者自身も完璧にはできなかったと述べている。
- 失敗してもすぐに切り替えて戻ること、失敗しても諦めないことを忘れないようにする。

## 6つのルールのまとめ

1. 自分が食べているものをちゃんと記録する（摂取カロリーの把握）
2. メンテナンスカロリーを把握する
3. タンパク質を体重の2倍摂取する
4. 筋トレ（週3回以上）と1日1万歩をライフスタイルとして当たり前に行う
5. 十分な睡眠をとる
6. 完璧主義ではなく継続主義になる

## コミュニティ・90日チャレンジについて（告知）

### 前回の90日チャレンジの実績

- 前回の90日チャレンジ（コミュニティ内企画）では、参加者の中に3ヶ月でとんでもない変化を遂げたメンバーが多数いた。
- 体だけでなくマインドも変わり、人生が変わるきっかけになったと語るメンバーもいた。
- 一方でかなりハードな内容だったため、参加者の中には途中で脱落・離脱した人もいた。

### 今回用意された2つのコース（90日チャレンジ2）

- **コース1：ハードコース**
  - 前回のチャレンジ内容と同様。90日間で体に大きな変化を起こしたい人、短期間で大きく体を変化させたい人向け。
- **コース2：習慣化コース**
  - 対象：ダイエット初心者、これまで何度もダイエットに失敗してきた人、ダイエットの成功経験がない人、仕事や学校が忙しくダイエット・トレーニングに時間を割けない人。
  - ハードコースに比べると90日間で起こる体の変化は少ないかもしれないが、一時的に痩せるためではなく、ダイエットを成功させる上で必要なライフスタイル・生活習慣を体に叩き込むためのコース。
  - この習慣化コースを90日間継続できれば、その後もダイエット成功まで継続できる可能性が高いとされている。

### コミュニティでやることのメリット

- **仲間の存在**：同じ目標（ダイエット・自分を変えたい）を持った仲間と出会え、モチベーションを高め合ったり悩みに答え合ったりできる。ダイエット中は孤独を感じやすく（話者自身も孤独を感じていたと述べている）、その心の支えになる。
- **知識面**：ダイエット完全ガイド、リバウンド阻止ガイド、食事やトレーニングに関する教材・情報が提供され、ダイエットに必要な情報はほぼ全て取り入れられる。
- **サポート環境**：話者本人に加え、優秀なゲストコーチ（パーソナルトレーナーやオンラインコーチとして活躍している人）が数名在籍しており、体重停滞などの悩みや疑問に回答・サポートしてくれる。
- コミュニティには**約600人**のメンバーが在籍している。
- コミュニティに入らなくてもダイエット自体は可能だが、知識面・メンタル面のサポートを受けられる点がメリットとして挙げられている。最終的に行動するかどうかは本人次第であるとも述べられている。
