# 2026-08-26 睡眠改善させる寝る前の食事

出典: Skool（SGIR HQ PREMIUM）・Sam Phillips

---

## 就寝1〜1.5時間前の推奨食事

### 推奨食材と理由

| 食材 | メカニズム |
|------|----------|
| ギリシャヨーグルト（乳製品） | メラトニン前駆体のセロトニン分泌を促進。トリプトファン豊富で睡眠の質改善に貢献 |
| グリーンキウイ | セロトニン含有。抗酸化・抗炎症作用で酸化ストレスと炎症を抑制。ミネラルが神経の安定をサポート |
| はちみつ | 血糖値の安定化による入眠しやすさ改善の可能性あり |
| カボチャの種 | トリプトファン豊富（トリプトファン→セロトニン→メラトニンに変換）。マグネシウムが神経の興奮を抑え、中途覚醒・入眠スピードを改善 |

### Samの実践レシピ
| 食材 | 量 |
|------|---|
| ギリシャヨーグルト | 250〜300g |
| グリーンキウイ | 2個 |
| カボチャの種 | 20g |
| はちみつ | 15g |
| プロテインパウダー | 半スクープ（エクストラタンパク質・味付け） |

全て混ぜて食べる。

### 体感効果
- 入眠スピードの明らかな改善（ここ数日間で実感）
